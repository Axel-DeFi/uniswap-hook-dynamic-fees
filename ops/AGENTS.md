# Ops AGENTS

Для live deploy- и ensure-фаз в итоговом сообщении обязательно указывать:

- сеть и выполненные фазы;
- `hookAddress`;
- `POOL_ID`;
- хеши onchain-транзакций деплоя и инициализации;
- ссылку на стандартный интерфейс Uniswap для добавления ликвидности.

Для Uniswap v4 не называй `POOL_ID` "адресом пула":
- отдельного адреса пула нет, потому что пулы живут в singleton `PoolManager`;
- если пользователю нужен ориентир для интерфейса и аналитики, указывай `hookAddress` и `POOL_ID`.
